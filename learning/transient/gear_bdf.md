# Gear 与后向差分公式：利用历史点处理刚性问题

## 1. Gear 法是什么

Gear 法通常称为后向差分公式（BDF）。它是隐式多步积分方法：使用多个已接受历史状态，但只使用当前新点的导数。因此适合把刚性电路的导数项转化为当前时间点的代数方程。

一般形式可写为：

```text
xn+1 = a1 xn + a2 xn-1 + … + ak xn-k+1 + b0 h x_dot,n+1
```

因为 `x_dot,n+1=f(xn+1,tn+1)`，它仍须用 Newton 解 `xn+1`。

## 2. Gear 1：向后欧拉

```text
xn+1 = xn + h x_dot,n+1
x_dot,n+1 ≈ (xn+1-xn)/h
```

Gear 1 为一级、A 稳定，历史只需一个点。

## 3. Gear 2：最重要的二阶 BDF

等步长下：

```text
xn+1 = 4/3 xn - 1/3 xn-1 + 2/3 h x_dot,n+1
```

等价地：

```text
x_dot,n+1 ≈ [3xn+1 - 4xn + xn-1] / (2h)
```

Gear 2 为二级且 A 稳定，通常是精度、阻尼与刚性适应性的实用折中。它需两个已接受时间点，不能在第一步直接使用。

## 4. 高阶 BDF

Gear 3 至 Gear 6 可通过更长的历史点构造更高阶后向差分。例如 Gear 3：

```text
x_dot,n+1 ≈ [11xn+1 - 18xn + 9xn-1 - 2xn-2] / (6h)
```

高阶带来更低的截断误差，却要付出更多历史管理、起步和变步长系数计算的复杂度。BDF 1、BDF 2 是 A 稳定；BDF 3～6 对刚性问题有用，但不再 A 稳定。

## 5. Gear 2 的电容伴随模型

由 `i=C dv/dt` 与 BDF2：

```text
iC,n+1 = (3C/2h) vC,n+1 + (C/2h)(vC,n-1 - 4vC,n)
```

所以：

```text
Geq = 3C/(2h)
Ihist = (C/2h)(vC,n-1 - 4vC,n)
```

它仍然是“电导加历史源”，只是历史源同时依赖两个过去的电压。

## 6. Gear 2 的电感伴随模型

由 `v=L di/dt`：

```text
iL,n+1 = (2h/3L) vL,n+1 + 4/3 iL,n - 1/3 iL,n-1
```

因此：

```text
Geq = 2h/(3L)
Ihist = 4/3 iL,n - 1/3 iL,n-1
```

## 7. 变步长的关键限制

上述常数系数只适用于等步长。若 `hn != hn-1`，不能机械复用 `4/3`、`-1/3`、`2/3`；需要根据实际时间节点重建差分/插值系数，或采用专门的 Nordsieck 历史表示。实现一个可靠变步长 Gear 求解器时，系数管理与状态回滚同样重要。

## 8. 阶数控制

典型策略是：起步、断点、误差增大或试算失败时降阶；波形平滑、历史充分且误差裕量较大时再升阶。高阶不自动等于更好，因为它更依赖可靠历史并有不同稳定边界。
