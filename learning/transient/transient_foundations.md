# 瞬态分析基础：从连续时间电路到逐点代数求解

## 1. 瞬态分析求什么

DC 工作点分析求的是静态解 `F(x)=0`：所有量不随时间变化。瞬态分析求的是一条状态轨迹：

```text
x(t0), x(t1), x(t2), …, x(T)
```

其中 `x` 通常包含节点电压、MNA 中电压源支路电流，以及需要显式保留的电感电流。电路更一般地写为：

```text
F(x, dx/dt, t) = 0
```

电容和电感使方程含导数：

```text
iC = C dvC/dt
vL = L diL/dt
```

因此，瞬态问题是带初始条件的微分—代数方程问题；初始状态通常来自 DC 工作点，也可以由用户给定。

## 2. 与 DC 分析的关系

在 DC 稳态中，`dv/dt=0`、`di/dt=0`，所以理想电容等效开路、理想电感等效短路。瞬态中它们保存能量，当前量还依赖过去状态。

```text
DC：        只问“最后停在哪里”
瞬态：      问“从初始状态怎样走到那里，以及中间发生什么”
```

非线性电路中，两者都要 Newton 法；区别是瞬态每个时间点都会生成一个新的、带历史项的方程。

## 3. 时间离散化

计算机不直接处理连续曲线，而取离散时间网格：

```text
t0 < t1 < … < tn < tn+1 < … < T
hn = tn+1 - tn
xn ≈ x(tn)
```

所谓数值积分，就是用 `xn+1` 与历史值近似 `dx/dt`。例如向后欧拉：

```text
dx/dt |n+1 ≈ (xn+1 - xn) / hn
```

代入 `F` 后得到只有 `xn+1` 未知的代数方程：

```text
Fn+1(xn+1) = 0
```

线性电路每步变成 `A xn+1 = b`；含二极管、BJT、MOS 等非线性器件时，每步变成 Newton 问题。

## 4. RC 阶跃：最小例子

对电阻 `R` 与电容 `C` 串联、输入为常值 `E` 的电路：

```text
RC dvc/dt + vc = E
vc(0) = v0
```

解析解为：

```text
vc(t) = E + (v0 - E) exp[-t/(RC)]
```

真实电路常包含非线性和多个储能元件，通常没有这种闭式解；但该式给出了校验数值积分的标准参照。

## 5. 两层循环

非线性瞬态分析的结构是：

```text
外层：选择 tn+1，控制时间步 hn
内层：在固定 tn+1 上 Newton 求 Fn+1(x)=0
```

Newton 迭代为：

```text
J(x(k)) Δx = -F(x(k))
x(k+1) = x(k) + Δx
```

上一个已接受解通常是很好的初值；更好的做法是先用历史值预测 `xn+1`。

## 6. 一个时间点为什么可能被拒绝

即使 Newton 收敛，也只能说明离散方程解得足够好；它不保证时间积分逼近真实连续解的误差足够小。一个试算点只有同时满足以下条件才能接受：

```text
1. Newton 收敛：当前代数方程被解出。
2. LTE 合格：时间离散误差在容差内。
3. 不越过已知激励/开关断点。
```

失败时必须恢复上一个已接受状态，缩小步长后重算。历史状态绝不能由失败点污染。

## 7. 本节结论

瞬态分析并不是与 DC 完全不同的求解器，而是把“建立方程—Newton 求解”重复放在时间推进中。新增的关键是：导数离散、储能历史、误差控制和状态回滚。
