# 振荡器瞬态分析实例：起振、初值与最大步长

振荡器是瞬态求解器的好检验对象：DC 工作点往往是平衡点，却不是最终波形；必须依赖时间推进、器件动态模型与合适初始扰动观察起振。

## 1. 考比兹振荡器：LC 选频与小信号起振

考比兹振荡器用电感 `L` 与电容分压器 `C1,C2` 形成选频与反馈网络。两串联电容的等效值为：

```text
Ceq = C1 C2 / (C1 + C2)
f0 ≈ 1 / [2π sqrt(L Ceq)]
```

晶体管从直流电源取得能量，补偿谐振网络损耗。振幅通常经历：

```text
微小扰动 → 环路增益放大 → 振幅增长 → 非线性限幅 → 稳态周期波形
```

### 为什么可能“不起振”

理想仿真没有热噪声和元件失配。若初始解刚好落在完全对称的静态平衡点，Newton 与积分器可能始终停在那里。这不是电路一定无法起振，而是数值模型缺少扰动。可通过很小的初始不对称或短暂电源扰动启动，但应明确其目的仅是打破平衡。

### `TMAX` 的作用

对频率 `f0`，周期 `T0=1/f0`。最大内部时间步必须远小于关键周期和最快边沿时间；否则求解器可能跨过起振增长或高频细节，数值阻尼还可能人为压制振荡。仅拉长 `TSTOP` 不能解决时间分辨率不足。

### 观察什么

* 起振等待时间与增长率；
* 稳态频率是否接近 LC 估算；
* 振幅是否被负载明显压低；
* 晶体管结电容、渡越时间等高频参数对相移和起振的影响；
* 梯形法振铃与真实谐振的区别。

## 2. 无稳态多谐振荡器：RC 充放电与再生翻转

两个交叉耦合 BJT、两个集电极电阻、两个基极电阻及交叉电容形成无稳态多谐振荡器。假设左管先导通、右管截止：左集电极变低，经交叉电容抑制右基极；随后右侧电容经电阻充电，右管开启又通过正反馈迅速使左管截止。状态不断反转，产生近似方波。

对近似对称电路，周期量级可估算为：

```text
T ≈ 2 × 0.693 RB C
```

实际周期还会受到 BJT 饱和、结电容和开关时间影响。

### 初值与 UIC 的意义

对称电路的精确对称 DC 解可能阻止数值翻转。可指定一侧集电极低、另一侧高，使一个晶体管先导通、另一个先截止。若希望直接采用这组动态初值，必须同时明确是否跳过默认 DC 初始化；不同 SPICE 方言对 `.IC` 与 `UIC` 的语义细节不同，使用时应以所用仿真器文档为准。

## 3. 两类振荡器的对照

| 项目 | 考比兹 | 多谐振荡器 |
|---|---|---|
| 主要波形 | 近似正弦 | 近似方波 |
| 频率主导因素 | LC 谐振 | RC 充放电 |
| 反馈 | 分压正反馈 | 交叉耦合再生反馈 |
| 数值难点 | 高频步长、起振扰动、器件高频模型 | 对称初值、快速翻转、断点/步长 |
| 有用观察量 | 频率、振幅、谐波、起振速度 | 周期、占空比、翻转边沿 |

## 4. 解释仿真结果时的原则

不要把“出现振荡”自动视为物理正确，也不要把“未出现振荡”立即视为电路错误。应依次检查：初始条件/扰动、最大步长、积分方法、LTE、器件动态参数与负载。尤其是梯形法的数值振铃可能很像真实高频振荡；改变步长或切换至 Gear/向后欧拉进行对照，是区分两者的有效方法。
