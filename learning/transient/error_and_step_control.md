# 误差估计与时间步控制：接受、拒绝与回退

## 1. 两类失败

瞬态程序必须区分：

```text
Newton 失败：当前离散方程在给定步长下未能收敛。
LTE 超差：离散方程已解出，但积分近似不够准确。
```

两者都要拒绝当前试算点、缩小步长并重算，但它们不是同一件事。

## 2. 局部截断误差（LTE）

LTE 假设进入当前步时历史值完全准确，只衡量本步积分公式替代微分方程产生的误差。

```text
向后欧拉：LTE = O(h^2)，全局误差 O(h)
梯形法：  LTE = O(h^3)，全局误差 O(h^2)
```

真实高阶导数未知，工程实现需用历史均差或预测—校正差估计。

## 3. 预测—校正误差估计

一种直观方式是先用显式方法预测，再用隐式方法校正：

```text
x_pred = xn + h x_dot,n                （向前欧拉）
x_corr = 隐式积分 + Newton 的收敛结果
```

两者差值反映当前步的离散误差，也为 Newton 提供较好的初值。必须注意：预测值不等于最终接受值。

## 4. 归一化误差

电路变量量纲和数量级不同，不能直接比较绝对误差。对每个变量可采用：

```text
ri = |Ei| / [ATOLi + RTOL max(|xi|, |xi_prev|)]
r = max_i ri
```

`r <= 1` 表示误差满足容差；`r > 1` 表示拒绝。电压和电流通常分别有绝对容差。

## 5. 根据误差选择下一步

若方法全局阶为 `p`，其本地误差主项按 `h^(p+1)` 缩放，可使用：

```text
h_next = safety * h * (1/r)^(1/(p+1))
```

常用 `safety` 小于 1，并限制变化比，例如：

```text
0.2 h <= h_next <= 2 h
```

对向后欧拉，指数为 `1/2`；对梯形法，指数为 `1/3`。误差为零或极小时，仍需由 `TMAX` 限制最大步长。

## 6. 由 Newton 行为辅助控制

Newton 迭代次数可作为经验信号：迭代很少，下一步可尝试放大；迭代很慢或失败，缩小步长。然而它不直接衡量积分精度，不能取代 LTE 控制。

## 7. 起步与多步法

一步法只有初值也可开始。Gear 2 及更高阶方法需要多个历史解，因而通常先以向后欧拉等低阶方法起步，待历史点充足再升阶。步长突变、断点和拒绝重算也可能要求暂时降阶。

## 8. 导数不连续与 breakpoint

脉冲源边沿、PWL 拐点和开关动作会使导数发生突变。求解器应让时间网格准确落在断点：

```text
h_trial = min(h_proposed, t_breakpoint - tn)
```

在断点及紧邻区域，向后欧拉通常比梯形法稳健，因为它不依赖断点左侧的旧导数。未知的快速变化则依靠 LTE、Newton 失败和减步长机制发现。

## 9. 试算状态的最小规则

```text
accepted_state：最后正式接受的解与器件历史
trial_state：   当前候选时间点
newton_state：  当前候选点内的迭代向量
```

只有 `trial_state` 同时通过收敛与 LTE 检查后，才能替换 `accepted_state`。这是变步长瞬态算法正确性的基础。
