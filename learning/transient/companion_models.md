# 储能元件伴随模型：电导加历史源

## 1. 核心思想

在固定试算时间点 `tn+1`，数值积分把动态元件变成代数支路：

```text
储能元件 = 当前未知量乘以等效电导 + 已知历史源
```

这称为伴随模型（companion model）。等效电导不是元件的真实物理电导；它依赖积分方法与当前时间步 `h`，每次重试或变步长后都必须重新计算。

以下采用支路电压 `u`、电流 `i` 的被动符号约定。

## 2. 电容的向后欧拉模型

电容关系为：

```text
iC = C duC/dt
```

用向后欧拉近似导数：

```text
iC,n+1 = C (uC,n+1 - uC,n) / h
         = (C/h) uC,n+1 - (C/h) uC,n
```

因此：

```text
Geq = C/h
Ihist = -(C/h) uC,n
iC,n+1 = Geq uC,n+1 + Ihist
```

`Ihist` 保存了过去的电荷状态。若漏掉它，电容会错误地退化为普通电阻。

## 3. 电容的梯形模型

梯形法使用两端电流：

```text
iC,n+1 = (2C/h)uC,n+1 - [(2C/h)uC,n + iC,n]
```

所以：

```text
Geq = 2C/h
Ihist = -[Geq uC,n + iC,n]
```

与向后欧拉相比，梯形法还必须保存上一个已接受点的电容电流。

## 4. 电感的向后欧拉模型

电感关系：

```text
uL = L diL/dt
```

将电流作为状态变量，得到：

```text
iL,n+1 = iL,n + (h/L)uL,n+1
```

它同样可写成 Norton 形式：

```text
Geq = h/L
Ihist = iL,n
iL,n+1 = Geq uL,n+1 + Ihist
```

电感的记忆来自旧电流；电容的记忆主要来自旧电压。这是二者的对偶关系。

## 5. 电感的梯形模型

```text
iL,n+1 = (h/2L)uL,n+1 + [iL,n + (h/2L)uL,n]
```

因此：

```text
Geq = h/(2L)
Ihist = iL,n + Geq uL,n
```

使用该模型时，需保存旧电感电流和旧电感电压。

## 6. MNA stamp

若支路连接节点 `p`、`q`，`u=Vp-Vq`，则任意 Norton 形式 `i=Geq(Vp-Vq)+Ihist` 的电导部分按普通电阻填入：

```text
Ypp += Geq     Ypq -= Geq
Yqp -= Geq     Yqq += Geq
```

历史源进入右端或残差。其正负取决于代码采用的 KCL/右端约定；最可靠做法是先以支路电流为基准把它加入两个节点残差，再对 `Vp,Vq` 求导。

## 7. 互感：必须整体处理

多个耦合线圈的关系不是彼此独立，而是：

```text
u = L i_dot
```

其中 `L` 是含自感和互感项的电感矩阵。向后欧拉给出：

```text
i_n+1 = i_n + h L^(-1) u_n+1
```

因此每个线圈除了自身电导，还会获得由其他线圈电压控制的耦合电流项。实现中应以一个耦合组为单位构造矩阵，而非把每个电感独立 stamp。

## 8. 步长与数值阻抗

向后欧拉下：

```text
电容：Geq=C/h      h 越小，等效电导越大。
电感：Geq=h/L      h 越小，等效电导越小。
```

这描述的是短时间内状态不易突变的数值表现。切勿只看等效电阻而忽略历史源。

## 9. 状态提交规则

伴随模型使用的历史量只能来自最后一个已接受点。当前试算收敛后先做 LTE 检查；仅在接受时才把 `u_n+1`、`i_n+1` 推入历史。拒绝时保留旧历史并以新步长重建模型。
