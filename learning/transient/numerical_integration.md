# 数值积分方法：用差分替代时间导数

考虑初值问题：

```text
x_dot = f(x, t),   x(t0) = x0
hn = tn+1 - tn
```

数值方法的目标是：已知 `xn`，计算 `xn+1`。下标表示时间点，不表示 Newton 迭代。

## 1. 向前欧拉：使用旧点斜率

在 `tn` 处的一阶泰勒展开给出：

```text
xn+1 = xn + hn f(xn, tn)
```

右侧全为已知量，所以它是显式方法。几何上，它沿旧点切线前进一步。

局部截断误差为 `O(h^2)`，全局误差为 `O(h)`，因此是一级方法。它实现简单，但稳定区域小；常用于预测或起步，较少单独承担刚性电路的主积分任务。

## 2. 向后欧拉：使用新点斜率

```text
xn+1 = xn + hn f(xn+1, tn+1)
```

新值出现在右侧，故为隐式方法。需要构造：

```text
G(xn+1) = xn+1 - xn - hn f(xn+1, tn+1) = 0
```

再用 Newton 求解。它同为一级方法，但具有强数值阻尼，适合刚性电路、起步和导数不连续附近。代价是快速变化的真实成分可能被过度衰减。

## 3. 梯形法：使用两端斜率平均

由积分关系 `xn+1-xn = ∫ x_dot dt`，用梯形面积近似得：

```text
xn+1 = xn + hn/2 [f(xn,tn) + f(xn+1,tn+1)]
```

它也是隐式方法。局部截断误差 `O(h^3)`、全局误差 `O(h^2)`，故为二级方法。它通常比向后欧拉精确，却可能在快速衰减或断点后表现出梯形数值振铃。

## 4. 三种公式的对照

| 方法 | 用到的斜率 | 类型 | 全局阶数 | 主要特点 |
|---|---|---|---:|---|
| 向前欧拉 | 旧点 | 显式 | 1 | 简单，稳定性限制严格 |
| 向后欧拉 | 新点 | 隐式 | 1 | 稳健，数值阻尼强 |
| 梯形法 | 新旧平均 | 隐式 | 2 | 精度高，可能振铃 |

## 5. 精度与稳定性不同

局部截断误差回答“当前公式近似连续系统有多准确”；稳定性回答“误差是否会在多次递推中被放大”。Newton 收敛只说明离散代数方程被求解，不能替代这两种判断。

对测试方程 `x_dot = λx`，数值解都有 `xn+1=R(hλ)xn`。当真实解衰减时，希望 `|R(hλ)|<1`。不同积分公式的 `R` 会在稳定性笔记中详细讨论。

## 6. 一步法与多步法

上述三种方法都只需要上一个历史时间点，因而是一步法。多步法还使用 `xn-1`、`xn-2` 等更多历史解，例如 Gear 2：

```text
xn+1 = 4/3 xn - 1/3 xn-1 + 2/3 h x_dot,n+1
```

“一步/多步”描述使用多少历史时间点；“一阶/二阶”描述误差随步长下降的速度，两种术语不能混淆。

## 7. 选择的直觉

```text
平滑且希望较高精度：梯形法常是好选择。
起步、开关边沿、Newton 困难或强刚性：向后欧拉更稳健。
需要利用较长历史并处理刚性：考虑 Gear/BDF。
```

积分方法一旦确定，就决定电容、电感的等效电导和历史源形式。
